# Boardgame Tutorial

ボードゲームのルールを、文章を読むだけでなく実際に操作しながら学べるブラウザチュートリアルをまとめるプロジェクトです。

## 方針

- スマートフォンで遊びやすいレスポンシブUI
- ゲームごとに独立したフォルダで管理
- 説明よりも、カードや盤面を操作する体験を重視
- 共通の画面設計・操作性を各ゲームで再利用
- イベント単位で公開期間を設定できるようにする

## ディレクトリ構成

```text
boardgame-tutorial/
├── README.md
├── app.py
├── baron-nimmt/
│   ├── home.html  # ゲーム一覧トップ
│   ├── index.html # ニムト男爵のモード選択
│   ├── draft.html
│   └── cpu.html
├── shared/
│   └── （共通スタイル・共通スクリプト）
└── server/
    └── （公開期間を制御するサーバー機能）
```

## イベント限定公開

公開期間は日本時間（JST）で管理します。

- 開始日時より前：アクセス拒否
- 公開期間中：チュートリアルを配信
- 終了日時以降：アクセス拒否
- 期間外はHTMLやゲームデータを配信しない

※ クライアント側の日時判定だけでは回避できるため、公開期間の判定はサーバー側で行います。静的ホスティング単体ではなく、サーバー側のアクセス制御を組み合わせる方針です。

## ゲーム追加手順

1. ゲーム名のフォルダを作成する
2. `index.html` と必要な画像・データを配置する
3. ルールと操作を実際にプレイして検証する
4. 公開期間を設定し、イベント用URL・QRコードを準備する
