# ニムト男爵 チュートリアル

## 公式説明書から確認した基本ルール

- 対象年齢：8歳以上、プレイ人数：2〜10人、プレイ時間：約30分
- 牛カードは110枚（数字1〜110）。青・黄・緑・赤・黒・白の牛マークが描かれている
- 全110枚をよく混ぜ、人数に応じた枚数を各プレイヤーに配って「自分の山札」にする（2人：24枚／3人：20枚／4〜6人：16枚／7〜8人：12枚／9〜10人：8枚）
- 手札は4枚ずつ：自分の山札から4枚引いて手札にする。ラウンド終了時に手札は補充しない。手札を全て出し切ったラウンドの終了時にのみ、自分の山札から4枚引く
- 配られなかったカードから5枚を表向きに並べ、各列の最初のカードにする。残りのカードはそのゲームでは使わない
- 全員が同時に1枚選び、公開後は数字の小さいカードから順に処理する
- 手札から毎回1枚ずつ選んでプレイする。全員が最後のカードを列に置いたらゲーム終了
- カードは列の最後尾に置く。置けるのは、最後尾カードに自分のカードと同じ色の牛マークが1つ以上ある列
- カードの数字は置く順番を決めるためのもので、置く列を決める条件ではない

## 列を引き取る条件

1. **6枚目のカード**：列の6枚目になる場合、前の5枚を引き取る。プレイしたカードはその列の新しい1枚目
2. **同色の牛マークが6つ以上**：カードを置いた列に同じ色の牛マークが6つ以上ある場合、前のカードをすべて引き取る。プレイしたカードは新しい1枚目
3. **色が合わない**：どの列の最後尾にも同じ色の牛マークがない場合、列を1つ選んでその列のカードをすべて引き取る。プレイしたカードはその列の新しい1枚目

## 得点・終了

- 引き取ったカードは表向きの「牛の山」に置く。手札や自分の山札には戻さない
- 各カード上部に記載された牛マーク数が失点
- 全員が最後のカードを列に置いたら終了。失点が最も少ないプレイヤーが勝ち。同点は引き分け

- 公開前に、カードの色・牛マーク数・列処理の具体例を実物カードと照合する
- 現在は基本ルール学習用の試作段階。実物カードの詳細データと全シナリオの最終検証後に公開する

## バリエーション（CPU対戦・オンライン対戦で選択式オプションとして実装済み）

- バリエーション1「色が大事」：6枚目を置いても列を引き取らない。引き取りは「同じ色の牛マークが6つ以上」と「置ける列がない場合」だけ
- バリエーション2「牛を集めろ」：牛の山は失点ではなく得点になる。どの列とも色が合わない場合、そのカードは列を引き取らず、自分の山札の一番下に入れる。少なくとも1人が最後のカードをプレイしたラウンドの終了後に終了し、牛の山の牛マークが最も多いプレイヤーの勝ち
