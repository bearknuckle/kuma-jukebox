コード進行のルールに沿ってカードを出し合い、手札を先になくした人の勝ち。

CPUの人数
ラウンド
3回戦は失点の合計で勝負
上級ルール
最後の1枚は C だけ

ルール

カード（全53枚）

  • トニック T：C×8、Am×6、Em×6
  • サブドミナント S：F×7、Dm×6
  • ドミナント D：G×8
  • 特殊：G7×3、sus4×3、リピート×3、ブレイク×3

準備

  • 1人7枚ずつ配る
  • 山札をめくり、最初に出た T のカードが場札

つなぎ方（T → S → D → T の一方通行）

  • T の後 → S か D
  • S の後 → D だけ
  • D の後 → T だけ
  • 同じコードなら、いつでも重ねられる（例：F→F、G→G）

手番

  • つながるカードを1枚出す
  • 出せないときは1枚引く。引いたカードが出せれば、そのまま出す。出せなければ手番は終わり
  • 山札がなくなったら、場の一番上以外をシャッフルして山札に戻す

特殊カード

  • G7：D扱い。次の人は T を出すか、2枚引いて手番終了。G7 に G7 を重ねてもよい（引くのは2枚のまま）
  • sus4：いつでも出せる（G7 を出された直後は除く）。次の人は何でも出せる
  • リピート：順番が逆回り（2人ならもう一度自分の番）
  • ブレイク：次の人は1回休み
  • リピート・ブレイクは D の後には出せない。場のコードは変わらない

上がり

  • 手札が最初になくなった人の勝ち
  • 最後の1枚は T でないと出せない。T 以外が1枚残ったら引くしかない（特殊カードでは上がれない）
  • G か G7 → C で上がると「完全終止」！

得点（3回戦）

  • 上がれなかった人は、残った手札1枚につき1点の失点
  • 完全終止で上がったら、ほかの人の失点は2倍
  • 山札切れで終わったときは、全員が残り手札の枚数だけ失点
  • ラウンドごとに最初の手番を次の人へ交代。3回終わって失点がいちばん少ない人の優勝（同点なら上がった回数が多い人）

上級ルール

  • 最後の1枚は C でないと出せない（Am・Em では上がれない）。しっかり「ド」で終わろう
